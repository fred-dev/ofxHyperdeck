# ofxHyperdeck

openFrameworks class for controlling Blackmagic HyperDeck recorders over TCP (the HyperDeck Ethernet protocol): play, record, stop, clip and timecode navigation, slot and input selection. `src/ofApp` is a small test app.

## Build

- No extra addons. Generate the project with projectGenerator.
- Set the HyperDeck's IP in `ofApp`.

Work in progress from 2014 and never fully tested against hardware.
